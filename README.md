# Bulk Carrier Kite Demo

## Windows / VS Code

PowerShellでこのフォルダを開き、以下を実行します。

```powershell
npm install
npm run dev
```

表示されたURL（通常は http://localhost:5173 ）をChromeまたはEdgeで開いてください。

## 内容

- バルクキャリアは基本座標固定
- 海面の波だけがアニメーション
- 船首のTowing Unit
- Unitからカイトへ伸びるライン
- カイトのFigure-eight / X flight
- カイト飛行軌跡
- 簡易的な船尾方向への白波
- マウスによるOrbitControls
